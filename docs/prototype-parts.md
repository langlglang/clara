## Gaps and checks before assembly

1. **Power path:** record the available battery's chemistry, capacity (Wh), connector, built-in protection, charger, and output range. Add an inline fuse and holder near the battery, sized for the chosen wiring and load. The buck converter makes 5 V but does not itself provide charging, backup switchover, or proof of Pi 5 USB-C 5 A power signaling. Verify the Pi's power input design on the bench; do not assume the bare-wire pigtail solves it. The hub's separate 5 V input also needs a rated source. A known-good [Pi 27 W USB-C supply](https://www.raspberrypi.com/products/27w-power-supply/) is useful for first bring-up, if one is not already available.
2. **Video connector:** the [screen listing's package contents](https://www.amazon.com/dp/B0CYKXCM8J) mention an HDMI cable and **mini-HDMI** adapter. Pi 5 uses **micro-HDMI**. The team has the screen cables; check them before buying an [appropriate cable/adapter](https://www.raspberrypi.com/products/micro-hdmi-to-standard-hdmi-a-cable/).
3. **Physical build:** add a movable camera mount or gooseneck, camera cable strain relief, screen mounting pieces, and labeled kit trays. The MAX30102 listing includes loose pin headers, so confirm access to a soldering iron, solder, insulation and a multimeter. Confirm each actual wire can reach its port with the lid open.
4. **Demo contents:** no first-aid supplies or props appear in this electronics list. Choose the fictional kit items, slot labels, and versioned layout together before showing item-retrieval visuals. See [kit inventory](subsystems/kit-inventory.md).
5. **Proposed compartment lights:** the team's newer [3 V prewired, 5 mm LED candidate with clips, Amazon B0B2L9FP4R](https://www.amazon.com/dp/B0B2L9FP4R) could use one ESP32 GPIO per slot with a separate series resistor per LED, after checking the delivered current and brightness. The listing does not clearly state whether a resistor is built in. Prefer red/amber for a low-current 3.3 V circuit. The earlier [12 V prewired candidate, Amazon B094YNNCC2](https://www.amazon.com/dp/B094YNNCC2) would require external switched drivers and a checked 12 V branch. Neither set or the resistors are in the selected list or subtotal. See [hardware wiring](hardware-power.md).
6. **Proposed anti-theft parts:** a buzzer for the open chime and a mount-removal switch on the wall bracket. The selected roller-lever switch listing may include spares; otherwise add one switch. Neither part nor a wall bracket is in the selected list or subtotal. See [anti-theft](subsystems/anti-theft.md).
7. **Second box for the network demo:** a mock box (a laptop or tablet running the box screen, optionally with a spare ESP32 and a few LEDs) needs no new purchase if the team already has a laptop and spare parts. A second physical box would roughly double the electronics list. See [box network](subsystems/box-network.md).

## Proposed connections with these selections

- Pi USB-A → ESP32 USB-C data cable; ESP32 GPIO → lid limit switch; ESP32 3.3 V I²C → MAX30102 after verifying the delivered breakout's pull-up setting and pinout.
- If the 3 V candidate is selected: one safe ESP32 output GPIO → series resistor → one LED → ESP32 ground per compartment. Pi sends the slot-light command over the existing ESP32 USB cable. The 12 V candidate needs external drivers instead.
- Pi micro-HDMI → Elecrow display; display USB → Pi or powered hub for touch/power. The screen's supplied leads must be checked for the Pi's plug type.
- Pi USB-A → selected speaker; hub → mic and camera, with GPS on a remaining hub port if used. Confirm real USB current and bandwidth; move devices if the hub cannot supply them.
- Pi Wi-Fi → cloud. The Pi stays powered with the screen idle while the lid is shut. The rocker is a **master** power switch; turning it off removes instant lid-open response.

No peripheral or battery operation is marked verified until it is tested on the delivered parts.
