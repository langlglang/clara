# Subsystem handoffs

| Guide | Owner's key question |
| --- | --- |

| [Agent and backend](agent-backend.md) | How are tools, versioned demo steps, and outages coordinated? |
| [Touchscreen UX](touchscreen-ux.md) | What does a stressed bystander see and control? |
| [Companion app](companion-app.md) | How does someone find a box and initiate SOS? |
| [Camera and sensors](camera-sensors.md) | What can be observed, and how is uncertainty shown? |
| [Kit inventory](kit-inventory.md) | How does the screen know what is physically inside? |
| [Mock SOS](emergency-workflow.md) | How does the simulated SOS work offline? |
| [Box network](box-network.md) | How do boxes report status and call nearby kits during an incident? |
| [Anti-theft](anti-theft.md) | How do we discourage theft without ever blocking emergency access? |
